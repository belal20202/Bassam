# «بسام» (Bassam Runner) 🏃‍♂️💨

**لعبة ركض ومطاردة عربية احترافية وكاملة تعمل مباشرة على المتصفح، الهواتف الذكية، وأجهزة الكمبيوتر، مع دعم كامل للتشغيل بدون إنترنت (100% Offline) وتوافق تام مع GitHub Pages وAndroid APK.**

---

### 🇮🇶 هوية اللعبة
- **اسم اللعبة:** بسام (Bassam Runner)
- **المطور:** بلال النعيمي
- **سنة الإنتاج:** 2026
- **بلد الصنع:** صنع في العراق 🇮🇶
- **النوع:** لعبة ركض ثلاثية الأبعاد لا نهائية (3D Endless Runner)
- **الجمهور المستهدف:** جميع الأعمار (أجواء كوميدية عائلية ممتعة)

---

## 🎮 قصة اللعبة وطريقة اللعب

يقوم الشاب الطموح والمرح **بسام** بخوض مغامرة ركض شيقة ومطاردة كوميدية عبر شوارع وأحياء المدينة العربية، متفادياً السيارات والحافلات والحواجز والحفر، بينما يطارده مفتش الحي الكوميدي!

### أزرار التحكم:
| الحركة | لوحة المفاتيح (كمبيوتر) | شاشة اللمس (موبايل) |
| :--- | :--- | :--- |
| **الانتقال لليمين** | سهم يمين أو حرف `D` | سحب بإصبعك لليمين (Swipe Right) |
| **الانتقال لليسار** | سهم يسار أو حرف `A` | سحب بإصبعك لليسار (Swipe Left) |
| **القفز للأعلى** | سهم فوق، مسافة `Space`، أو `W` | سحب بإصبعك للأعلى (Swipe Up) |
| **الانزلاق والدحرجة** | سهم أسفل أو حرف `S` | سحب بإصبعك للأسفل (Swipe Down) |
| **إيقاف مؤقت** | حرف `P` أو زر `Esc` | النقر على زر الإيقاف في زاوية الشاشة |

## ✨ المميزات الرئيسية للعبة

1. **رسومات ثلاثية الأبعاد أصلية 100%:**
   - زاوية كاميرا خلفية متتبعة مع منظور عمق ديناميكي وسلس بمعدل 60 إطاراً في الثانية.
   - شوارع عربية أصيلة، أشجار نخيل، مبانٍ بتصاميم وأقواس عربية، إضاءة متغيرة (نهار، غروب، ليل).

2. **20 زياً كاملاً ومتنوعاً لشخصية بسام:**
   - بسام الكاجوال (مجاني)، الرياضي، الشتوي، الرحالة، الطالب، لاعب الكرة، رجل الأعمال، المغامر، الصحراوي (بالكوفية)، الليلي، الذهبي، الناري، البرق، الأسطوري، الملكي، السريع، الفضائي، الظل، النادر، وبسام الأسطوري النهائي!

3. **5 قدرات خارقة قابلة للترقية (1 إلى 5 مستويات):**
   - **الدرع الواقي (Shield):** يحمي بسام من الاصطدام المفاجئ.
   - **مغناطيس العملات (Magnet):** يجذب كل العملات في الطريق.
   - **الإبطاء الزمني (Slow Motion):** يبطئ حركة العالم لتخطي العقبات الصعبة.
   - **مضاعف العملات (Multiplier 2x):** يضاعف قيمة العملات المجمعة.
   - **الاندفاع الصاروخي (Boost):** سرعة فائقة وحصانة نارية تحطم كل ما أمامها!

4. **10 مهمات يومية متجددة:**
   - ركض مسافات محددة، جمع العملات، القفز والانزلاق، وتفعيل القدرات مع جوائز نقدية ونقاط خبرة (XP).

5. **نظام التقدم والمستويات:**
   - شريط خبرة، ارتقاء في المستويات، ومكافآت عملات عند كل مستوى جديد.

6. **تقويم المكافآت اليومية (7 أيام متتالية):**
   - هدايا متصاعدة يومياً، تنتهي بزي "بسام الصحراوي" الأسطوري في اليوم السابع.

7. **متجر وصناديق الحظ (Chests):**
   - 4 أنواع من الصناديق (عادي، نادر، ملحمي، أسطوري) بنسب حظ حقيقية وجوائز ثمينة.

8. **لائحة الصدارة المحلية (Leaderboard):**
   - تصنيف متصدرين بأسماء عربية يتنافسون مع أفضل رقم قياسي تحققه في الركض.

9. **محرك أصوات وموسيقى تفاعلية (Web Audio API):**
   - نغمات وإيقاعات عربية أصيلة يتم توليدها برمجياً دون الحاجة إلى ملفات mp3 ثقيلة، وتعمل بدون أي تأخير زمني.

10. **100% Offline & PWA:**
    - حفظ البيانات عبر `LocalStorage` مع نظام تحقق ونسخ احتياطي واستعادة تلقائية.
    - دعم تطبيق الويب التقدمي (PWA) عبر `manifest.json` و `service-worker.js`.

## 🚀 النشر على GitHub Pages

المشروع جاهز فوراً للرفع والنشر عبر GitHub:
1. ارفع الكود إلى مستودعك على GitHub.
2. توجه إلى **Settings** > **Pages**.
3. اختر مصدر النشر: **GitHub Actions** (سيعمل ملف `.github/workflows/deploy.yml` تلقائياً).
4. ستعمل اللعبة فوراً على رابط مجاني وسريع!
